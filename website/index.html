Advantages

Built for real repos, not demo prompts.

Groveyard gives an MCP-capable agent a predictable workspace and a narrow set of tools. The agent can create a session, inspect files, run configured checks, show a diff, and commit the work without touching your active tree.

Isolation

Agents work in disposable branches

Every task starts in a Git worktree with a tracked session id, branch, base branch, and cleanup path.

Control

Commands come from your config

Run test, lint, build, or typecheck profiles without handing the agent arbitrary shell access.

Review

Status and diff are first-class

The MCP flow pushes agents to inspect changed files before saying a task is done.

Setup

Connect detects local agent configs

Groveyard finds Codex, Claude Desktop, and Cursor config locations, then asks before creating files.

Use cases

Let agents move faster while Git stays legible.

Use Groveyard when multiple coding agents, background tasks, or experiments need to work around the same repository without stomping on local changes.

Parallel agent tasks

Spin up independent sessions for bug fixes, refactors, and docs without dirtying your base checkout.

Safe command execution

Expose only named command profiles, then let the agent run the checks that matter for that repo.

Cleaner review handoff

Ask the agent for the session branch, diff, and commit SHA instead of hunting through a mixed tree.

Connect once. Work in sessions.
